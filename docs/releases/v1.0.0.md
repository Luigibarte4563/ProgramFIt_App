# Release v1.0.0

**Release date:** 2026-08-06
**Tag:** `v1.0.0`

## Overview

Welcome to the first public release of **ProgramFit**! ProgramFit is a career
assessment system that helps students discover university programs that align
with their interests. This offline MVP runs entirely on-device — no accounts,
no backend, and no cloud services.

## ✨ New Features

- **Instant launch** — the app opens straight into the home screen with no
  login or account setup required.
- **Two-phase interest assessment** that tailors questions to the student's
  interests and chosen departments.
- **Top-3 program recommendations** ranked by fit, with flagship-program
  fallbacks and fit/confidence badges.
- **Local progress persistence** — assessment progress and results survive
  app restarts.

## 🚀 Improvements

- Neo-brutalist **Material 3** design system with custom widgets (cards,
  buttons, badges, dialogs, and progress bars).
- Responsive layout with an app navigation bar across all supported platforms.
- Cross-platform support: Web, Android, iOS, Windows, macOS, and Linux.

## 🐛 Bug Fixes

- None — initial release.

## ⚠ Known Issues

- The app is an **offline MVP**: data is stored only on the device and is not
  synced across devices.
- Only the Android APK is published as an installable release asset in this
  version.

## 📥 Installation

1. Open the **[Latest Release](https://github.com/Luigibarte4563/ProgramFIt_App/releases/latest)** page.
2. Download **`app-release.apk`** from the **Assets** section.
3. If prompted, enable **Install unknown apps** on your Android device.
4. Install the APK and open the app.

For the web version or running from source, see the
[README](https://github.com/Luigibarte4563/ProgramFIt_App#readme).

## 🔄 Upgrade Notes

This is the first release, so there is no previous version to upgrade from.
Future upgrades will preserve your data as long as the application ID remains
the same.

## 👨‍💻 Developer Notes

- **Stack:** Flutter (Material 3), Dart `^3.12.2`, `go_router`, `shared_preferences`.
- **Build the release APK locally:**

  ```bash
  flutter build apk --release
  ```

  The APK is written to `build/app/outputs/flutter-apk/app-release.apk`.

- **Release automation:** releases are created automatically by GitHub Actions
  when a version tag (`v*`) is pushed. See
  [`.github/workflows/release.yml`](https://github.com/Luigibarte4563/ProgramFIt_App/blob/main/.github/workflows/release.yml).
